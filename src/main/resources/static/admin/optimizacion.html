Optimizar promociones

Asigna el presupuesto de publicidad y el tiempo de asesores para maximizar la comisión esperada.

Modelo matemático de programación lineal

Para cada inmueble seleccionado, la intensidad xᵢ representa la fracción de su campaña completa que se ejecutará: 0 significa no promocionarlo y 1 significa ejecutar la campaña completa. Solo debes llenar los datos de las propiedades que quieras incluir.

Maximizar Z = Σ comisión esperadaᵢ × xᵢ Σ presupuesto de publicidadᵢ × xᵢ ≤ presupuesto disponible Σ horas de asesorᵢ × xᵢ ≤ horas disponibles 0 ≤ xᵢ ≤ 1 para cada inmueble
